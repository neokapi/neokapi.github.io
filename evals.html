Tests and Evals

Three bands, by what is under test. kapi's own code can be asserted. A model's output can only be estimated. An agent's behaviour is scored scenario by scenario. Inside each band the structure is the architecture.

Foundations

architecture

The content model every format is read into, how a piece of content is identified, and the wire schema that carries it.

E

Engine

architecture

Reading a format, running tools over the content, binding flows, and writing the document back unchanged where nothing was edited. Rests on the content model being able to hold what the format carried.

AI and context

C

Context

architecture

What governs content at the point it sits: the coordinates, the voice profile, the terms, and the content memory holding what was already approved. Rests on the engine putting the right content in front of the governance.

M

Multilingual

architecture

The call itself: what goes into a prompt, how many blocks travel together, and how the text was split before any of that. Rests on the context layer having resolved what applies before a prompt is built.

A

Assurance

architecture

The checks that read finished content and report what breaks the rules, and whether they are right about it. Rests on every layer below, since a check reports on what they produced.

Agent skills

1 measured2 partial
SubjectAn agent driving kapi: the shipped Agent Skill, and the MCP tools an assistant calls.EvidenceScenario-scored. A prompt and a workspace go in, and what the agent did comes out: which tool it reached for, whether it finished at a green gate. No model grades anything. Triggering is stochastic, so a scenario means little until it is repeated.Gates CINo, and these never run in CI. They drive an interactive agent on a maintainer's machine, so the committed dataset is all CI sees and the date on it is the real currency of the numbers.
S

Surfaces

architecture

How kapi is reached: the CLI, the desktop app, the shipped Agent Skill, and the MCP tools an assistant calls. Rests on every layer below, since a surface is how a person or an agent gets at them.
